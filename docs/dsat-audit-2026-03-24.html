🚫 Ship Blockers

3 Critical — Must resolve before release
CRA-001
updater.rs — unwrap() on HTTP JSON parsing
If GitHub API returns malformed JSON (rate limit HTML page, 500 error, network truncation), the emulator panics on the menu screen. Users see an unexplained crash on every launch when GitHub is having issues.
updater.rs:47
CRA-002
cartridge.rs — ROM loading panics on corrupted files
Multiple unwrap() calls on file reads during ROM loading. Any truncated, corrupted, or misidentified .nes file crashes the emulator instead of showing a user-friendly error. This is the #1 user-facing operation.
cartridge.rs
SEC-001
Auto-updater has no binary integrity verification
The updater downloads binaries from GitHub Releases over HTTPS but performs zero post-download verification — no checksums, no signatures. A compromised GitHub account or CDN MITM could deliver arbitrary executables to every user on next update.
updater.rs

⚡ Quick Wins

12 fixes — each under 10 lines of code
CRA-001
Replace updater unwrap() with error dialog
Change .unwrap() to .unwrap_or_else() with a log warning. Show "Update check failed" in OSD instead of panicking.
updater.rs:47~3 lines
CRA-007
APU blip_buf unwrap → graceful fallback
Replace .unwrap() on buffer creation with .expect("OOM") or return a Result. Only triggers on memory exhaustion.
apu.rs~2 lines
CRA-008
FM2 export — handle read-only paths
Replace .unwrap() on file creation with a match/if-let and show OSD error "Cannot write recording file".
recording.rs~4 lines
CRA-010
Lua eval crash on malformed scripts
Replace .unwrap() on lua.load() with error handling that logs the Lua error and disables the script.
scripting.rs~4 lines
CRA-006
Netplay packet length validation
Change data.len() >= 2 to data.len() >= 15 (minimum valid packet size). Reject short packets before indexing.
netplay.rs~1 line
UX-006
Persist CRT filter selection to config
Add crt_filter_mode field to config struct and save/load it. Users currently re-select every launch.
config + main.rs~5 lines
UX-008
Persist fullscreen state to config
Save F11 fullscreen toggle to config file. Restore on next launch. Same pattern as CRT filter fix.
config + main.rs~4 lines
SEC-006
Sanitize SRAM save file paths
Strip path separators and .. from ROM filenames before constructing SRAM paths. Prevents directory traversal.
cartridge.rs~3 lines
UX-004
Audio fade on pause/unpause
Apply a 5ms linear fade-out before pause and fade-in on resume to eliminate the audible pop/click artifact.
apu.rs / main.rs~8 lines
PERF-005
Move update check to background thread
Wrap the ureq update check in std::thread::spawn so slow/unreachable networks don't freeze the UI for up to 30 seconds.
main.rs:~2050~5 lines
UX-005
Show error overlay on bad file drop
When drag-and-drop of a non-.nes file occurs, display an OSD error instead of silently staying on the menu.
main.rs~5 lines
SEC-004
Add ROM size sanity check
Validate iNES header PRG/CHR sizes against actual file size before allocating buffers. Reject ROMs claiming >16MB.
cartridge.rs~5 lines
