# MMC3 A12 IRQ Gate Diagnostic Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make MMC3 scanline IRQ clocking respect whether rendering can drive PPU A12 high, and prove it with a generated diagnostic cartridge.

**Architecture:** Keep the existing scanline-level MMC3 approximation, but gate the scanline clock behind active background/sprite pattern-table sources that can raise PPU A12. Add a generated Mapper 4 variant that first renders with background pattern table `$0000` and expects no IRQ, then switches to `$1000` and expects one IRQ.

**Tech Stack:** Rust PPU/mapper runtime, generated diagnostic iNES cartridges, host telemetry, Python diagnostic verifiers, Cargo tests.
